# Manual de Cadastro (EXEMPLO FICTÍCIO — substitua pela documentação real)

## Abertura de conta Pessoa Jurídica
Documentos obrigatórios:
- Contrato social ou estatuto atualizado;
- Cartão CNPJ emitido há menos de 30 dias;
- Documento de identidade e CPF dos sócios administradores;
- Comprovante de endereço da empresa emitido há menos de 90 dias.

## Atualização cadastral
Alteração de endereço pode ser feita pelo app, com envio de comprovante emitido há menos de 90 dias.
O cadastro deve ser revalidado (KYC) a cada 24 meses.
